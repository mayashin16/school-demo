🎓 Школа: Путь к мечте (Демо-версия)

Добро пожаловать в демонстрационную версию геймифицированного школьного приложения! 
Этот проект создан для того, чтобы показать, как работает механика обучения, строительства и получения наград в игровом формате.

Все данные (прогресс, покупки, построенные здания) сохраняются **локально в вашем браузере** (в `localStorage`). Серверная часть и база данных не требуются.

🚀 Как запустить (Docker)

Самый простой способ запустить приложение — использовать готовый Docker-образ. 

Выполните в терминале:
`docker run -d -p 8080:80 mayashin/school-demo:latest`

✨ Что есть в демо-версии?
📚 Задания: 50 уникальных заданий (25 по Математике и 25 по Русскому языку), доступных для всех классов (с 1 по 6).
🎮 Геймификация: Зарабатывайте Искры (валюту) и Опыт (XP) за правильные ответы.
🏫 2D-Карта школы: У вас уже есть главное здание и ворота. Остальное нужно строить!
🛒 Магазин: Покупайте ресурсы (дерево, камень, кирпич) за Искры.
🏗️ Развитие: Стройте заборы и деревья. У каждого здания есть таймер строительства.
🗑️ Сброс прогресса: На главном экране есть кнопка очистки всех данных, чтобы начать заново.
